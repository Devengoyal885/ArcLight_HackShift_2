# CapAble Design System

> Last updated: auto-generated by AI agent audit. Keep this file in sync when tokens.css changes.

## Foundation

CapAble uses a **dark-first glassmorphism design** built on CSS custom properties.
All tokens are defined in `src/styles/tokens.css`.

---

## Color Palette

### Primary
- `--color-primary`: Core brand blue/indigo
- `--color-primary-hover`: Lighter hover variant
- `--color-primary-subtle`: Very light tint for backgrounds

### Surfaces
- `--color-bg`: Page background (darkest)
- `--color-surface`: Card/panel background
- `--color-surface-elevated`: Elevated panel (modal, dropdown)
- `--color-border`: Default border color

### Text
- `--color-text`: Primary text (high contrast)
- `--color-text-muted`: Secondary text
- `--color-text-subtle`: Tertiary/placeholder text

## Glassmorphism Recipe

For glass panels (modals, sidebars, floating cards):
```css
background: rgba(var(--color-surface-rgb), 0.7);
backdrop-filter: blur(16px);
-webkit-backdrop-filter: blur(16px);
border: 1px solid var(--color-border);
border-radius: var(--radius-xl);
```

---

## Motion / Animation

Always use **Framer Motion**. Key presets:

```tsx
// Fade in from below (page/section entry)
initial={{ opacity: 0, y: -10 }} animate={{ opacity: 1, y: 0 }}

// Staggered card list (add delay: i * 0.04)
initial={{ opacity: 0, y: 20 }} animate={{ opacity: 1, y: 0 }}

// Modal scale-in
initial={{ opacity: 0, scale: 0.96 }} animate={{ opacity: 1, scale: 1 }}

// Slide from right (panel)
initial={{ opacity: 0, x: 20 }} animate={{ opacity: 1, x: 0 }}
```

Duration: `0.2s` default, `0.3s` for modals.
