## 📊 PRIORITY ACTION MATRIX

### 🔴 CRITICAL (Build Immediately — These are table-stakes)
1. **Dark / Light mode toggle** — Every competitor has it
2. **Save/Bookmark jobs** — Most basic job platform feature
3. **Profile completion meter + suggestions** — LinkedIn's #1 engagement driver
4. **Global search with autocomplete** - ✅ Done
5. **Salary display on job cards** — Users won't apply blind
6. **Bulk CSV student import** — Institution TPOs cannot function without it
7. **PDF/Excel report export** — Institution & employer critical need
8. **Two-Factor Authentication (2FA)** — Security requirement
9. **Mobile bottom navigation** — 60%+ users on mobile
10. **Empty state illustrations** — Platform looks broken without content
11. **Error pages (404, 500)** with helpful links - ✅ Done
12. **"Mark all read" + grouped notifications** - ✅ Done
13. **Job search bar with filters** (company, salary, location, CGPA cutoff)
14. **One-click apply** — Remove friction from application
15. **Interview feedback from employer** visible to candidate

1. **Candidate comparison tool** — Employer critical need
2. **Offer letter generation (PDF)** — Employer → Candidate flow
3. **Self-schedule interview link** — Remove scheduling friction
4. **Skill gap visualization vs. desired role** — Career feature
5. **ATS keyword score for resume** — Jobscan equivalent
6. **Company-specific question bank** — High-engagement prep feature
7. **Announcement board for institution** — TPO daily need
8. **Progressive Web App (PWA)** — Installable on mobile
